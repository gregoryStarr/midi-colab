# MIDI Colab - Real-time Collaborative Music Creation

## Project Overview
MIDI Colab is a revolutionary web application that enables musicians to collaborate in real-time through a shared virtual piano interface. Players can select from multiple instrument sounds and create music together across different browser tabs with instant synchronization.

## Stitch Project ID
**stitch_project_id**: midi-colab-realtime

## Site Vision
Create an immersive, professional music collaboration platform that feels like a high-end digital audio workstation combined with the social experience of jamming with friends online. The interface should inspire creativity while providing intuitive controls and stunning visual feedback.

## Target Audience
- Musicians looking to collaborate remotely
- Music educators teaching in virtual classrooms
- Hobbyists exploring collaborative music creation
- Audio engineers testing real-time synchronization

## Core Experience
- **Instant Collaboration**: Play notes that appear simultaneously across all connected sessions
- **Professional Sound**: Six distinct instrument types with realistic synthesis
- **Visual Feedback**: Stunning piano interface with real-time key lighting
- **Modern UI**: Glassmorphism design with smooth animations and particle effects

## Technical Stack
- React + TypeScript frontend
- Web Audio API for sound synthesis
- WebSocket + Yjs for real-time synchronization
- WebContainer for client-side music processing
- Tailwind CSS for responsive styling

## Design Philosophy
- **Immersive**: Full-screen experience that draws users into music creation
- **Professional**: Clean, modern interface suitable for serious musicians
- **Collaborative**: Visual cues that emphasize shared creation
- **Responsive**: Works seamlessly across desktop and tablet devices
