Complete redesign of the MIDI Colab application using the established design system for a professional, immersive music collaboration experience.

**DESIGN SYSTEM (REQUIRED):**
# Design System: MIDI Colab - Real-time Collaborative Music Creation
**Project ID:** midi-colab-realtime

## 1. Visual Theme & Atmosphere
MIDI Colab embodies a **futuristic music studio** atmosphere - sleek, professional, and immersive. The design creates a sense of being inside a high-end digital audio workstation with holographic interfaces floating in a deep space environment. Glassmorphism effects suggest advanced technology while maintaining approachability for musicians of all skill levels.

## 2. Color Palette & Roles
- **Cosmic Purple (#6366f1)**: Primary brand color for active states and gradients
- **Electric Blue (#3b82f6)**: Secondary accent for status indicators
- **Neon Cyan (#06b6d4)**: Success states and engine controls
- **Vibrant Pink (#ec4899)**: Sound selection and creative elements
- **Sunset Orange (#f97316)**: Warnings and secondary actions
- **Deep Space Black (#0f172a)**: Primary background
- **Midnight Blue (#1e293b)**: Secondary backgrounds
- **Soft Gray (#64748b)**: Text and secondary elements

## 3. Typography Rules
**Primary Font Stack**: 'Righteous' for display + 'Poppins' for body text
- Display headings with tight letter-spacing and bold weights
- Professional body text with clean readability
- Gradient text effects for important elements

## 4. Component Stylings
* **Glass Cards**: Multi-layered backdrop blur with subtle transparency
* **Gradient Buttons**: Rounded corners with hover scale effects
* **Status Indicators**: Animated circular badges with color coding
* **Interactive Controls**: Hover states with particle effects

## 5. Layout Principles
**Asymmetric Sidebar Layout**: Fixed sidebar for controls, flexible main area for piano
**Generous Whitespace**: 6-8 units between sections
**Z-index Hierarchy**: Clear depth relationships
**Responsive Grid**: Adaptive layouts for different screens

## 6. Design System Notes for Stitch Generation
**Core Visual Language**: Glassmorphism, dynamic gradients, particle systems, neon glows
**Animation Philosophy**: Micro-interactions, floating elements, smooth transitions
**Typography Scale**: 7xl hero titles down to base UI labels
**Component Patterns**: Gradient borders, multi-layer glass, animated indicators
**Anti-patterns**: Flat interfaces, generic colors, static elements, poor contrast

**Page Structure:**
1. Immersive header with animated background and floating particles
2. Hero section with dramatic typography and feature highlights
3. Professional sidebar with engine controls and sound selection
4. Main piano interface with stunning visual feedback
5. Activity feed with real-time collaboration metrics
6. Smooth animations and particle effects throughout

**Key Features to Highlight:**
- Real-time collaborative music creation
- Professional instrument sounds (6 types)
- Instant cross-tab synchronization
- Stunning glassmorphism interface
- Particle effects and smooth animations
